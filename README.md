# Tilo Módulo 9

**Plataforma SaaS multiempresa para catálogos digitales, pedidos y gestión comercial.**

🌐 https://tilo.cl

---

## Sobre el proyecto

Tilo es una plataforma digital desarrollada para pequeños comercios y
emprendedores que necesitan centralizar la administración de sus productos,
catálogos y procesos comerciales.

El proyecto nació a partir de la necesidad de simplificar tareas que normalmente
se realizan utilizando distintas herramientas, permitiendo administrar información
comercial desde una única plataforma.

Tilo ha evolucionado progresivamente incorporando nuevas funcionalidades y
una arquitectura multiempresa que permite que diferentes negocios puedan
utilizar el sistema de forma independiente.

---

## Problema

Muchos pequeños negocios administran sus productos, pedidos y comunicación
con clientes mediante distintas herramientas o procesos manuales.

Esto puede generar:

- Información dispersa.
- Duplicación de tareas.
- Dificultad para mantener productos y precios actualizados.
- Falta de centralización de los procesos comerciales.
- Mayor tiempo destinado a tareas administrativas.

---

## Solución

Tilo centraliza diferentes procesos comerciales dentro de una aplicación web.

La plataforma permite administrar productos y catálogos digitales, recibir
pedidos y utilizar distintas herramientas orientadas a facilitar la operación
de pequeños negocios.

---

## Funcionalidades

## Arquitectura

Tilo utiliza una arquitectura multiempresa que permite que múltiples negocios
utilicen la misma plataforma manteniendo sus datos y procesos organizados de
forma independiente.

El backend separa responsabilidades mediante modelos, controladores, rutas
y servicios, facilitando el mantenimiento y la incorporación de nuevas
funcionalidades.

---

## Caso de estudio

### Desafío

El principal desafío fue transformar una necesidad comercial amplia en una
plataforma sencilla de utilizar y preparada para evolucionar.

Además de desarrollar funcionalidades, fue necesario considerar la experiencia
del usuario, organización de datos, escalabilidad y separación entre distintas
empresas dentro de la plataforma.

### Solución desarrollada

Se creó una aplicación web centralizada capaz de administrar productos,
catálogos, pedidos y otros procesos comerciales.

La plataforma se desarrolló de forma progresiva, incorporando nuevas
funcionalidades a medida que se identificaban necesidades y oportunidades
de mejora.
